# 九州风云

网页版多人策略战棋游戏（历史架空题材）。单文件 HTML，浏览器打开即玩，零依赖、可离线运行。

## 快速开始

1. 下载 `九州风云.html`
2. 用浏览器（推荐 Chrome / Edge）双击打开
3. 选择文明，开始对局

支持本地存档/读档与战报导出，适合线下聚会或热座联机（共享屏幕轮流操作）。

## 玩法简介

- **十二文明**：秦、汉、晋、隋、唐、宋、明、顺、契丹、女真、蒙古、党项，各自拥有专属特性、建筑与特殊兵种
- **回合流程**：准备阶段（收入结算 → 外交 → 招募/建造/发展）→ 行动阶段（调动 / 进攻）
- **兵种词条**：远射、弹幕、破阵、奔袭、冲锋、水战、据守、列阵、重甲、火力、攻城、游击、协同、机动、爆破、死战……
- **地形系统**：山地/沙漠/森林/丘陵等影响攻防，跨河跨海有惩罚，飞地有补给短缺
- **发展度与城市**：每地块可提升发展度、建造/升级城市（最高 4 级），城市等级影响收入与可招募兵种
- **游牧进化**：契丹→辽、女真→金、蒙古→元、党项→夏，达成条件后改国号并获得新特性/兵种
- **战斗**：骰子对决（d6 + 战力加成 − 地形惩罚），兵种有优先攻击顺序，全灭守军可顺势占领

完整规则见 [规则书.md](规则书.md)。

## 技术说明

- 原生 HTML / CSS / JavaScript，无任何外部依赖与联网请求
- 地图基于地块（province）系统，数据驱动
- 存档使用浏览器 localStorage
- 战报可导出为纯文本
